# app_web — Capa de Usuario (UX/UI)

Interfaz de usuario del proyecto NeuroSync.

## Contenido esperado
- App móvil (o vista web responsiva) para **estudiantes**: registro, visualización de estado emocional, micro-intervenciones (ej. ejercicios de respiración).
- **Dashboard** para orientadores/docentes: alertas, tendencias y estado general del grupo.

## Estructura sugerida
```
app_web/
├── src/
│   ├── componentes/
│   ├── paginas/
│   └── servicios/        # llamadas a api_backend
├── public/
└── package.json
```
